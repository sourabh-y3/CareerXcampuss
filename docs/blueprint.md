# **App Name**: CareerXCompass

## Core Features:

- User Authentication: Secure user authentication using Firebase Authentication (Email, Phone, Google Sign-In).
- Aptitude and Interest Quiz: Interactive quiz to assess student aptitude and interests.
- Personalized Career Roadmap: Visual roadmap displaying personalized career paths based on quiz results. Includes backup options.
- College Directory and Comparison: Directory of government and private colleges with side-by-side comparison features. College data will be sourced from Firestore.
- AI Career Guidance Chatbot: AI chatbot (integrated with Gemini API) that provides career guidance, college comparison explanations, and answers student queries. It will act as a tool to incorporate course to career options.
- Personalized Recommendations: Use Vertex AI-style logic for aptitude scoring and personalized course recommendations.
- Notifications and Timelines: Smart notifications and timelines for admission and scholarship deadlines using Firebase Cloud Messaging.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and professionalism.
- Background color: Light blue (#E3F2FD), a very lightly saturated tint of the primary color, for a calm and uncluttered feel.
- Accent color: Purple (#7E57C2), an analogous color that's used to highlight key actions.
- Headline font: 'Space Grotesk' sans-serif for a techy, scientific feel; body text: 'Inter' sans-serif for longer text passages
- Use clear and intuitive icons representing different career paths, college types, and assessment categories.
- Student-friendly UI with a focus on clear information hierarchy and accessibility.
- Subtle transitions and animations to guide users through career roadmaps and college comparisons.
